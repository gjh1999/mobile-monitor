# 澜汐文件与 Codex 消息同步引擎评测

**评测包 v1.0 · 2026-11-23**。适合横向比较多个模型从需求到可运行软件的能力。每次评测使用一个服务端、两个独立的本地客户端和合成数据。首次提交与一次修复分别评分。

## 如何发题

1. 先填写[评分与结果记录](评审专用/评分与结果记录.md)的运行条件。给所有模型相同的操作系统、CPU、内存、依赖下载权限、可用工具、时间上限和修复机会。记录各模型实际可选的思考档位。默认首次提交 120 分钟，修复 30 分钟，下载及构建时间计入。
2. 为每个模型准备一个独立的空工作区，把 [参测材料](参测材料/) 的**内容**复制到根目录。工作区放在澜汐仓库外，只向参测模型开放该工作区。保留相同版本的初始文件。评审目录和本仓库的 Git 历史由评审者持有。
3. 开一个新对话，粘贴[任务书](参测材料/任务书.md)开头的提示词。结束时保存提交号或源码包哈希、原始对话、工具用时和额度变化。截止时尚未交付也保留现场。
4. 在独立的评审工作区从干净副本启动提交物。先按[公开测试说明](参测材料/公开测试说明.md)验收，再按[验收手册](评审专用/验收手册.md)运行隐藏场景。每个模型使用相同的输入字节，每次重启保留本轮状态目录。
5. 冻结首次评分后，按统一模板反馈失败表现。允许一次修复，使用新空环境重跑**全部**用例，保留两轮成绩。最后并列比较核心验收、分数、耗时、额度与人工干预次数。

本包仅包含评测材料。模型成绩、运行日志和测量结果在实际开测后填写。
