# 工单 B · 审查匿名导出补丁

有人为任务表的 JSONL 导出功能提交了分页改造，公开测试已通过。你是合入前的评审人。请比对 base 和 proposed 两个快照，可以运行代码和写临时验证脚本。最终只提交 REVIEW.md，给出合入决定，最多列三条你能用代码或实验证实的问题，按对用户的影响排序。每条注明快照内位置、触发条件、期望、实得及复核方法。如认为可以合入，写清已检查哪些行为。

独立作答时间 35 分钟，Python 3.10+ 标准库。两个快照均可用 `python -m unittest discover -s tests` 在各自目录运行。

**既有导出约定。** 输入为导出开始时取得的固定列表，每行有唯一字符串 id、整数 updated 和布尔 archived。输出是一个 UTF-8 JSONL 文件。只输出未归档行，按 (updated, id) 升序，每条恰好一次。同一时间多条更新是正常业务。page_size 为正整数，决定每次读取的上限。目标可能已有上次成功的文件。整次导出成功后才发布新文件；读取或编码失败时向调用者报错，保留上次成功的文件。空结果应成功生成空文件。单进程单次导出，不涉及并发写入。
