# 澜汐安装、升级与验收

已发布的 R51 便携 ZIP 顶层包含主程序、`开始使用.txt` 和可选的 `IDE上报工具.zip`。验收功能内置于主程序。 [发布与验收记录](DELIVERY_STATUS.md#hook-approval-decisions) · [IDE 安装步骤](PROJECT_CONTROL.md#个人版项目占用)

## 在另一台 Windows 电脑使用

已连接本工作区的 Windows 电脑可以在澜汐内选择「检查更新」。手动换版时，从托盘退出旧版，再解压并启动新版。

新电脑只需从发布机复制 `release/笔记本下载/下载澜汐最新版.cmd` 到本地可写目录，双击即可。私人脚本会为当前 Windows 用户自动配对，下载服务器上的最新稳定版 ZIP 到脚本旁，并校验大小和 SHA-256。已配对的电脑会复用自己的身份。这个脚本含工作区加入授权，只在自己的设备之间传递。

若首次打开 R36 提示「打开或迁移用户数据失败」，且错误末尾是 `data\desktop-profile.json` 找不到，请关闭弹窗，用发布机上的新版 CMD 替换原下载脚本，放在已下载的 ZIP 旁再运行一次。脚本会补齐首次启动记录并校验现有 ZIP。随后直接打开原先解压的 EXE，沿用已有配对。

也可以直接复制已交付的私人 ZIP。两种方式下载或复制完毕后，按下面的步骤启动。

1. 将便携包解压到目标电脑本地可写目录。
2. 双击便携目录里的 `Lanxi-Glass-R51-Portable.exe`，在启动窗口选择「连接云服务器」或「本机使用」。代码同步需要 Git for Windows，终端接续需要本机安装并登录 Codex CLI。
3. 首次使用时选择本机项目母目录。启动后，可在顶部菜单栏点击「连接云服务器」。同一私人包的各台电脑连接后会加入同一个工作区。 [云服务器连接说明](CLOUD_COORDINATOR.md#在澜汐中连接云服务器)

鼠标移到窗口顶边，点「合流」可立即安排一轮同步，结果分别显示 GitHub、服务器代码备份、记忆及大文件清单的情况。 [手动同步](PERSONAL_SYNC.md#手动同步)

## 升级与首次配置

### 在已经用澜汐的电脑升级

R23 或更早版本可手动升级。从托盘退出旧澜汐，解压并打开新版。若旧版使用固定用户数据目录，新版会立即读取原有配置。早期版本的数据放在旧 EXE 同目录时，可按提示选择旧版目录迁移。旧目录保留作备份。

从 R24 起，HTTPS 配对成功后澜汐会定期检查更新。也可以从托盘点「检查更新」。已配对电脑需要单独下载 ZIP 时，可运行[下载最新版脚本](../scripts/download-latest-portable.cmd)。确认后程序下载并校验 ZIP，把新版放进 `%LOCALAPPDATA%\Lanxi\versions` 下的独立版本目录，再正常退出并打开新版。若当前有运行中的对话或待处理审批，程序先保留已下载的新版，等结束后再点一次「检查更新」切换。

升级到 R41 后首次打开，澜汐会在当前 Windows 用户的开始菜单登记「澜汐」，供退出后重新启动。程序运行时，也可从托盘选择「打开程序所在目录」。在旧版本上找升级后的 EXE，可按 `Win + R` 打开 `%LOCALAPPDATA%\Lanxi\versions`，进入相应的 `Lanxi-R…-Portable` 目录。

迁移完成后，配置、配对、项目索引、对话记录、随记、待办和本机草稿保存在 `%LOCALAPPDATA%\Lanxi\data`。托盘的「打开用户数据目录」可查看。今后换安装目录也会读回这份数据。项目文件、Codex 原生记忆和会话按原位置使用。

### 选择项目母目录

两台电脑可以选不同盘符。来源机在母目录下的 `客户甲\工具组\项目 A`，在新设备上也会克隆到所选母目录的 `客户甲\工具组\项目 A`。直接在这里打开、修改代码。项目记忆目录随项目一起对齐。

首次使用时，选存放各个项目的上一级文件夹，例如 `D:\Projects`。澜汐识别 Git 仓库和带常用项目文件的目录，会在 Codex 案头加入可启卷的项目条目，并归拢有对应本机路径的 Codex 会话。选择项目条目可查看分支、记忆位置和发现的记忆文件。项目目录里新建或克隆项目后，后台每约五秒更新一次。托盘的「设置项目母目录」可随时重设。

## 跨机借用与回传大文件

从托盘「跨机接续 → 查看大文件清单」查看本机缺少或大小不同的文件，以及项目内相对路径、大小和上次清点设备。Git 已跟踪且本机已有的 100 MiB 及以上文件自动登记。Git 忽略的文件可在同一菜单选择「登记大文件」。

1. 在目标电脑打开「跨机接续 → 借用另一台电脑的大文件」，选择文件和来源电脑。两台电脑的澜汐需运行并连接同一个个人空间。
2. 等「查看大文件借用与回传」显示「借用电脑可编辑」，再打开目标电脑项目内相同相对路径的文件。
3. 保存后在「查看大文件借用与回传」选择该记录提交回传。来源电脑核对原版 SHA-256，匹配时应用修改并保留本机恢复副本。原文件有新改动时显示冲突，两端各保留自己的内容。

成功和冲突均会写入交接记录，协调服务随后清理临时文件。服务器至少预留 5 GiB，空间不足时可在借用记录查看原因。 [大文件同步规则](PERSONAL_SYNC.md#保存更新与大文件)

## 运行验收

可从顶部菜单栏点击「测试」，或右键 Windows 右下角的澜汐托盘图标选择「测试」。如果图标被折叠，先点任务栏的 `^`。当前版本号见顶栏「澜汐 → 关于澜汐」。

已连接云服务器时打开窗口会直接运行服务器测试，未连接时运行本机自检。测试窗口也提供「连接云服务器」。本机自检需要 Git for Windows，使用独立副本、临时代码仓库和会话，检查空工作区克隆、代码和项目记忆同步、全局 `AGENTS.md`、已完成会话，以及达到 100 MiB 的文件留在源端。R38 还在临时普通项目验证无 GitHub 登录时的本地首提交、凭据文件过滤、超过 10 MiB 的会话分块接收和原 ID 接续。

「服务器测试」用当前设备身份检查服务接口、读回测试数据并清理。检查结果会标明失败或跳过的项目。单击「项目会话诊断」，选择实际项目目录，可查看本机仓库、接续索引、匹配的会话文件和大小。已连接时，普通项目按母目录下的相对路径比对服务器登记和会话数，Git 项目按仓库标识比对。点「复制结果」即可分享窗口中的报告。

各模式都生成 JSON 报告，路径显示在测试窗口中，通常位于 `%LOCALAPPDATA%\Lanxi\验收报告`。

本机自检还会用临时数据验证随记归档与分组、每日记录及待办回传、审批守卫、IDE 占用、大文件清单和备份 ZIP 过滤。服务器测试会对专用随机记录做一次写入、回读及清理，再读取项目占用、仓库、会话、记忆、大文件、随记、共享审批快照、备份目录及更新清单。索引查询返回零条时表示服务器当前没有对应记录。检查备份目录只读取元数据，实际项目的文件恢复与真实 IDE 的交互需分别验收。

同一个 GitHub 项目要在两台电脑上验收控制权时，先在第一台接入任务，第二台应显示项目被占用。第一台完成轮次后点击「交还任务」，等同步完再从第二台接入。IDE 上报插件需另外安装一次。 [跨设备项目控制](PROJECT_CONTROL.md#个人版项目占用)

## 终端和澜汐接着同一段对话

从终端切到澜汐时，等当前一轮结束并退出 Codex，再到「案头诸事」点开原会话，接入后就能在「灯下对谈」继续发消息。原终端还占用会话时，澜汐显示已保存的对话并等候写权限。

从澜汐切回终端时，在「案头诸事」右键点原来的 Codex 会话，选「查看会话 ID」，在弹窗点击「复制 ID」。解除澜汐对该会话的接入，再用同一 ID 在终端恢复。也可在 Codex 终端里用 `/status` 查看 ID。

新终端进入同一项目后，`codex resume` 会打开会话选择器。只想继续当前目录最近一次会话，用 `codex resume --last`。同一项目有多个任务时，直接指定会话 ID。

```powershell
codex resume -C "E:\Projects\A" "原会话的 UUID"
```

换电脑时，等澜汐同步项目和已完成的会话记录，再用该电脑的项目路径和同一个 ID 运行上面的命令。内置测试可检查会话记录传递，实际续写使用原会话 ID 验收。 [Codex CLI 命令参考](https://learn.chatgpt.com/docs/developer-commands?surface=cli#codex-resume)
